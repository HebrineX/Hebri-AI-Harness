# Prompt: Auditar y Reportar

Usar cuando el operador pide auditoria y salida clara para decidir.

1. Declarar contrato y validar binding.
2. Leer `orquestador/method/audit-reporting-policy.md`.
3. Ejecutar auditoria con `auditor(profile: harness_compliance|release|pipeline|security|architecture|detractor)`.
4. Completar `orquestador/sdd/progress/templates/audit-report-contract.md`.
5. Pasar a `reporter(profile: operator|technical|executive)` sin cambiar veredicto.
6. Reportar hechos, inferencias, riesgos y decisiones requeridas.
