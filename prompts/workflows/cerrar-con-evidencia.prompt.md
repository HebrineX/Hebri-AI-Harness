# Prompt: Cerrar con Evidencia

Usar antes de declarar `done`, cerrar fase o finalizar ciclo.

1. Declarar contrato y validar binding.
2. Leer `orquestador/method/final-report-evidence-policy.md`.
3. Leer gate log, audit trail, verification matrix, agent closure, locks y gaps.
4. Completar `orquestador/sdd/progress/templates/final-report-crosslink-checklist.md`.
5. Bloquear si el final report no permite reconstruir que paso.
6. Cerrar solo si no quedan agentes, locks o gaps bloqueantes sin declarar.
