---
description: "Definir tipo y escala de un proyecto nuevo antes de crear archivos"
---

Antes de crear cualquier archivo, necesito entender el proyecto.

1. ¿Cuál es el objetivo principal? (una frase)
2. ¿Qué stack? (lenguaje + versión, framework, herramienta de test)
3. ¿Solo o en equipo?
4. ¿Escala esperada? Chico / Mediano / Grande / No sé
5. ¿Hay reglas de dominio configurables? (YAML rules, políticas, etc.)
6. ¿Hay integraciones externas? (APIs, bases de datos, infra)
7. ¿Qué CI o herramienta principal usás? (GitHub Actions, Claude, otro)

Con esas respuestas propongo: estructura de carpetas, AGENTS.md base,
PROGRESS.md inicial y lista de gaps de partida desde la biblioteca
de Hebri-AI-Structure Vol 06.

No se escribe código hasta tener esos artefactos.
