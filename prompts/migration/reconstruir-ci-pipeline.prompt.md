# Prompt: Reconstruir CI o Pipeline

Usar cuando el operador muestra fallos, capturas o logs de CI/pipeline.

1. Declarar contrato y validar binding.
2. Leer `orquestador/method/ci-pipeline-policy.md`.
3. Leer workflows, scripts, logs, commits y evidencia externa provista.
4. Completar `orquestador/sdd/progress/templates/ci-pipeline-history.yaml`.
5. Listar cada iteracion relevante hasta llegar al estado actual.
6. No colapsar intentos si explican la decision final.
7. Pedir `SI` antes de editar workflows, scripts o changelog.
