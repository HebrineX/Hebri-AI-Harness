# Prompt: Reconstruir Deploy o Migracion

Usar cuando el operador pide documentar, auditar o corregir deploys/migraciones.

1. Declarar contrato y validar binding.
2. Leer `orquestador/method/deploy-migration-policy.md`.
3. Leer fuentes disponibles: scripts, workflows, logs, README, changelog, commits y reportes.
4. Completar `orquestador/sdd/progress/templates/deploy-migration-checklist.md`.
5. Separar prueba de concepto, CI, staging y produccion.
6. Presentar gaps y pedir `SI` antes de editar.

Bloquear si no hay evidencia de comando, entorno o resultado.
