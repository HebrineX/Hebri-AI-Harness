# Brief Operativo (Template)

Este es el contrato para enviar tareas a un subagente (Worker).

```text
Objetivo:
  [Una frase verificable, ej: Implementar Slice 2.1 según specs]

Contexto:
  Stack: [lenguaje, framework, versión]
  Estado actual: [qué existe hoy]
  Decisiones relevantes: [referencias]

Restricciones:
  - No tocar [archivo o carpeta].
  - Ownership exclusivo en: [archivos de los que es dueño].

Archivos relevantes:
  - [ruta] — [para qué sirve]

Salida esperada:
  - [artefacto, qué es y dónde se guarda]

Verificación:
  [Comando concreto, ej: dotnet test --filter X]

Riesgos:
  - [Qué podría romperse si se improvisa]
```
