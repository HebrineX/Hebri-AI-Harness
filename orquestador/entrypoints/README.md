# Entrypoints

Los entrypoints son procedimientos de arranque/reentrada. No reemplazan al contrato: lo rehidratan.

| Entrypoint | Uso |
|---|---|
| first-message | primer mensaje operativo en un proyecto |
| reentry-light | recuperar foco sin leer todo |
| reentry-full | auditoria o reconstruccion profunda |
| debug-log-intake | recibir logs sin ejecutar directo |
| compactation-recovery | volver despues de compactacion/resumen |
