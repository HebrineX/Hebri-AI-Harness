# AI Adapters

Los adapters traducen el contrato del harness a distintas herramientas de IA. No son fuentes de verdad. La fuente de verdad sigue siendo `.hebrinex`.

## Regla universal

Si una IA no soporta subagentes reales, debe declarar roles simulados como bloques trazables y no afirmar que ejecuto subagentes externos.

## Adapters incluidos

- `generic-ai.md`
- `codex.md`
- `claude-code.md`
- `gemini.md`
- `qwen.md`
- `deepseek.md`
- `cursor.md`
- `copilot.md`
