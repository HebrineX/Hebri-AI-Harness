# Analysis Checklist

Usar antes de ejecutar una implementacion, migracion, auditoria o cierre.

## Requisitos

- [ ] Requisitos identificados.
- [ ] Criterios de aceptacion claros.
- [ ] No objetivos declarados.

## Constraints

- [ ] Stack/comandos conocidos.
- [ ] Ownership definido.
- [ ] Politicas de tools revisadas.

## Riesgos

- [ ] Riesgos tecnicos.
- [ ] Riesgos de costo/token/contexto.
- [ ] Riesgos de seguridad/secretos.
- [ ] Riesgos de trazabilidad.

## Evidencia esperada

- [ ] Comando o verificacion.
- [ ] Archivos de evidencia.
- [ ] Gate log.
- [ ] Agent closure.
